Supported DEM Formats & Help

Supported Formats:

  • GeoTIFF (.tif, .tiff) - uncompressed, LZW, or Deflate compression
  • World files (.tfw, .tifw) for coordinate information
  • Projection files (.prj) for coordinate system
  • Data types: 8-bit, 16-bit, 32-bit integer or float

Not Supported (requires conversion):

  • LERC, JPEG2000, or WebP compression
  • HFA (.img), ASCII Grid (.asc), HGT (SRTM) formats

gdal_translate -co COMPRESS=NONE input.tif output.tif
