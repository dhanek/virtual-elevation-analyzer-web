## Interaction Invariants (BEHV-03 / BEHV-04)

These are the critical interaction contracts that extraction must preserve. They are the primary risk surface for this phase.

### BEHV-03: In-place update tab and scroll retention

| Invariant | Description |
|-----------|-------------|
| Tab persistence | When `updateGpsLapVEPlots` or `updateOutAndBackVEPlots` re-renders plots after slider/auto-adjust changes, the currently active ve-tab-button must remain active. The user must not be bounced back to the default "VE" tab. |
| Scroll persistence | The viewport scroll position must not jump during in-place plot updates triggered by slider changes or auto-adjust. |
| Trigger paths | Slider input changes (CdA, Crr), auto-adjust recalculation, wind source changes. All must preserve tab + scroll. |

### BEHV-04: GPS air-speed calibration correctness

| Invariant | Description |
|-----------|-------------|
| Calibration parameter flow | `airSpeedCalibrationPercent` from AppState must flow correctly through `resolveWindSeries` in both GPS-lap and out-and-back update paths. |
| Multi-segment settings persistence | `resolveMultiSegmentAnalysisParams`, `saveCurrentMultiSegmentSettings`, `saveMapTrimSettings` must produce identical save/load behavior after extraction into `analysis/MultiSegmentSettings.ts`. |
| Mode-specific wind resolution | GPS-lap passes `windSource` parameter explicitly. Out-and-back calls `getSelectedWindSource()` from DOM. Both patterns must be preserved as-is during extraction. |
