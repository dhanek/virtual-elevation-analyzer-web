## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Analyze Selected Laps** (when laps selected, disabled state: "Select Laps to Analyze") |
| GPS Mode Selector Label | **GPS Analysis Mode** |
| GPS Mode Options | "None" / "GPS based lap splitting" / "GPS based out and back" / "GPS gate one way" |
| Empty State Heading | **No Laps Detected** |
| Empty State Body | GPS analysis mode selected but no virtual laps detected. Adjust gate position on the map to define lap boundaries. |
| Error State | GPS detection failed. Please check that the ride file contains valid GPS coordinates and try again. |
| Mode Switch Warning | Switching modes clears previous detections. Continue? |
| Destructive Confirmation | **Clear GPS Detection**: This will remove all detected laps and markers. Continue? |

**Destructive Actions:**
1. Mode switch that clears detections — requires inline confirmation (no modal)
2. Clear GPS Detection button in panel header — uses standard confirm() dialog

## UI Components for Phase 2

### GPS Mode Selector Dropdown

**Placement:** Top of Section 3 sidebar, above Lap Selection panel (D-01, D-02)

**Visual Specification:**
- Matches existing `.param-item select` styles in CSS
- Border: 1px solid #d4d4d4
- Border-radius: 2px
- Padding: 0.5rem (sm)
- Background: white
- Font-size: 14px
- Label: "GPS Analysis Mode" positioned above (14px, weight 500, color #2d3748)
- Focus state: border-color #4363d8, box-shadow 0 0 0 1px #4363d8

**Behavior:**
- Default value: "None" when GPS file loaded (D-11)
- Change triggers immediate behavior change (D-06)
- No "Apply" button — state updates synchronously

### GPS Detection Panel (when mode != "None")

**Appears below Lap Selection when showGpsLapDetection or showOutAndBack is true**

**Visual Specification:**
- Background: #f7fafc
- Border: 1px solid #e2e8f0
- Border-radius: 2px
- Padding: 0.5rem
- Margin-top: 0.5rem (matches gap pattern)

**Panel Header:**
- h4 style: 14px weight 500, color #2d3748, border-bottom 2px solid #ff6b00 (GPS accent)

### Panel Visibility Transitions

- Panels appear/disappear without animation (instant visibility)
- Map visualization updates immediately when mode changes (D-09, D-10)
- Previous detections cleared on mode switch (D-07)

## Focal Point & Visual Hierarchy

**Primary screen:** Section 3 sidebar — the GPS mode selector at top draws initial attention
**Secondary:** Map visualization (right side) showing GPS track
**Tertiary:** Lap selection list and GPS detection panel

## Layout Structure

```
Section 3 Sidebar (320px min-width, flex: 0 0 320px)
├── GPS Mode Selector Dropdown (NEW - D-01, D-02)
├── Lap Selection Panel
│   ├── Header: "Lap Selection"
│   ├── Select/Deselect All button
│   └── Scrollable lap list
├── GPS Detection Panel (conditional - GPS mode != "None")
│   ├── Header: "GPS Virtual Lap Detection" / "Out & Back Detection"
│   ├── Gate slider controls
│   └── Detected laps/sections list
└── Map Trim Controls (fallback when GPS mode = "None")
```

**Responsive:** At ≤768px, layout stacks vertically (sidebar above map)
