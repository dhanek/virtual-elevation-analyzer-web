Define and export:

```typescript
/** Dependencies a shell module needs but cannot own. Passed in from main.ts. */
export interface ShellDependencies {
  state: AppState;
  getActiveMode: () => string;
  createVeCalculator: (rho: number, cdA: number, crr: number, mass: number, elevationData?: Float64Array) => any;
  createVeCalculatorWithRhoArray: (rhoArray: Float64Array, cdA: number, crr: number, mass: number) => any;
  log: typeof import('../../utils/log');
}

/** What a shell module can trigger after it completes its work. */
export interface ShellCallbacks {
  onAnalysisComplete?: (result: unknown) => void;
  onError?: (error: Error) => void;
}

/** Minimal shape of the prepared analysis payload that gets passed to shell renderers. */
export interface AnalysisPayload {
  mode: string;
  calculator: unknown;
  initialResult: unknown;
  filteredIndices: number[];
  rho: number;
  cdA: number;
  crr: number;
  mass: number;
  windSource: string;
  elevationData?: Float64Array;
}
```

Do NOT include DOM nodes or Plotly references in these types — only state and service references that `main.ts` already constructs.

  <action>
In `prepareAnalysisPayload.ts`:
- Export `function prepareAnalysisPayload(deps: ShellDependencies): AnalysisPayload`.
- This function should extract from `deps.state` and the analysis parameters the values needed to construct an `AnalysisPayload`:
  - Read the active mode from `deps.getActiveMode()`.
  - Read cdA, crr, mass, windSource, and elevation data from `deps.state` or DOM parameter inputs.
  - Resolve filtered indices using existing `SegmentExtractor` logic patterns.
  - Create the VE calculator via `deps.createVeCalculator` or `deps.createVeCalculatorWithRhoArray`.
  - Compute the initial result.
  - Return the assembled `AnalysisPayload`.
- Keep the function as a **pure data transform** — no DOM queries, no Plotly, no side effects. All DOM-dependent reads should be passed in via `ShellDependencies` or read from `AppState`.

In `prepareAnalysisPayload.test.ts`:
- Test `prepareAnalysisPayload` with a mock `ShellDependencies` that returns controlled values.
- Verify the returned `AnalysisPayload` has the correct mode, calculator, and parameter fields.
- Test that it throws or returns a meaningful error when state is incomplete.

In `shellController.ts`:
- Export `function runAnalysisShell(deps: ShellDependencies, callbacks?: ShellCallbacks): void`.
- This function calls `prepareAnalysisPayload(deps)` to get the payload.
- Then routes to the appropriate mode handler via `AnalysisModes` (already existing).
- Calls `callbacks.onAnalysisComplete` with the result if provided.
- Catches errors and calls `callbacks.onError` if provided.

In `index.ts`:
- Re-export `ShellDependencies`, `ShellCallbacks`, `AnalysisPayload` from `types.ts`.
- Re-export `prepareAnalysisPayload` from `prepareAnalysisPayload.ts`.
- Re-export `runAnalysisShell` from `shellController.ts`.
