3. It calls `runAnalysisShell(deps, { onAnalysisComplete: ..., onError: ... })`.

The key constraint: `handleAnalyze` should shrink by moving the **payload assembly and mode routing** into the shell controller. It should still own the top-level parameter reads and the construction of the dependency object.
